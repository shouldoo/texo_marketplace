# Pattern architetturali

Pattern architetturali, flussi e workaround collaudati, riutilizzabili tra organizzazioni diverse del settore.

Un pattern arriva qui quando una soluzione serve una seconda volta, su progetti diversi: prima è una lezione
del hub senza cliente, poi si riscrive in astratto, si verifica su una fonte pubblica (il codice di Odoo o di
OCA) e entra con una pull request rivista. Nessun nome di cliente, persona, istanza o host.
