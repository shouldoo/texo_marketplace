# Glossario di uno studio di progettazione

Ogni riga è un gruppo di termini equivalenti: la sigla, il nome per esteso e le parole con cui la stessa cosa
si dice in un cantiere, in una gara o in una mail di un committente. Quando la domanda contiene uno di questi
termini, gli altri del gruppo si passano alla ricerca come termini correlati (`texo search "<parole>" --terms ...`):
una nota scritta con «acconto alla ditta» si trova anche cercando «SAL».
